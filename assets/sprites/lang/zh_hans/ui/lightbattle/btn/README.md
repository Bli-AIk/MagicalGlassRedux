# 中文按钮贴图（zh_hans）

把中文版按钮 PNG 放到**本目录**（与英文文件同名，覆盖 `assets/sprites/ui/lightbattle/btn/` 的对应贴图；
kristal-i18n 的 `lang/zh_hans/` 命名空间会优先加载）。

需要提供的 32 个文件名（8 组 × 4 态；`_a`/`_d`/`_h` 为选中/暗面/悬停态）：

```
act.png       act_a.png   act_d.png   act_h.png
defend.png    defend_a.png  defend_d.png  defend_h.png
fight.png     fight_a.png   fight_d.png   fight_h.png
item.png      item_a.png    item_d.png    item_h.png
magic.png     magic_a.png   magic_d.png   magic_h.png
mercy.png     mercy_a.png   mercy_d.png   mercy_h.png
save.png      save_a.png    save_d.png    save_h.png
spare.png     spare_a.png   spare_d.png   spare_h.png
```

尺寸/规格与原英文贴图一致即可（字符颜色可跟随英文相同配色，字宽按中文排版微调）。
